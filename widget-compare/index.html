Same widget, four frameworks

한국어

The feedback card that npx create-lithent my-widget --template widget creates, built four times: with lithent, React, Preact and Lit. Each build is one <script> file, framework included, that any page can load. Same features, same stylesheet, same build settings, and one browser test runs the same steps on all four.

Bundle size

One minified IIFE per version, built by Vite with the same target and production mode. React and Preact also carry a small hand-written Custom Element wrapper (source), the job lithent/element and LitElement do in the other two.

Try them

Each frame is the template’s demo page, a stand-in for a customer’s website, loading one of the four bundles. Rate, send, reject a send, switch the page, the labels or the theme: all four answer the same way.

How this was made

  • The same widget. The lithent build is the template’s own source (FeedbackWidget.tsx). The other three are written the way each framework is usually written: function components with hooks for React and Preact, a LitElement for Lit. All four use the template’s stylesheet and props declaration. e2e/widget-compare.spec.ts runs the same steps on each in Chromium, Firefox and WebKit on every pull request: attributes, an Object property, events, a cancelled submit, slots, ::part, CSS variables and a strict Content-Security-Policy.
  • The same build. scripts/build.mjs builds all four with one Vite configuration: library mode, one IIFE, target es2020 / Safari 14, NODE_ENV=production. Only the JSX import source differs.
  • The same load. scripts/measure.mjs serves the files brotli-compressed, as a CDN would, and loads each version’s page in Chromium. The mobile profile uses Lighthouse’s mobile defaults through DevTools throttling. Rounds rotate the order of the four versions.

What this does not show

  • One small widget. It says nothing about rendering large apps or about developer experience.
  • Lab times from one machine. Compare the versions with each other rather than reading the numbers as what your visitors will see.
  • Other Custom Element wrappers for React or Preact would change their sizes.
  • A page that already runs React or Preact could share its runtime with a widget built for it. This compares widgets that bring everything they need, for pages you do not control.
