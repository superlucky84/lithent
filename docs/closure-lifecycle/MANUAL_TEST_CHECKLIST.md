# MANUAL_TEST_CHECKLIST — 1단계

자동 검증은 Node/jsdom의 base·concurrent 조합에서 수행했다.
아래 브라우저·실서비스 확인은 아직 수행하지 않았다.

- [ ] Chromium·Firefox·Safari에서 취소를 무시하는 느린 검색 A 다음에 B를 실행하고 결과·오류·pending이 B를 따른다.
- [ ] 위젯 제거 직후 응답이 도착해도 observer가 실행되거나 DOM이 되살아나지 않는다.
- [ ] 네트워크 취소가 서버 저장의 롤백을 의미하지 않는다는 설명을 실제 저장 API와 대조한다.
- [ ] 같은 태스크의 Custom Element 이동에서는 인스턴스와 작업이 유지되고 실제 제거 때 정리된다.
- [ ] 폐기 후 비동기로 얻은 자원은 즉시 정리되며, 정리 오류가 나도 다른 등록과 자식이 정리된다.
- [ ] CSP가 적용된 호스트에서 코어와 별도 실험 UMD를 로드하고 동작을 확인한다.
- [ ] 실제 ESM 앱에서 헬퍼를 사용하지 않을 때와 사용할 때의 최종 다운로드 크기를 비교한다.

화면 숨김·재활성화·DOM 상태 보존·portal·state-ref 구독 중단은 이번 프로토타입의 지원 범위에 없다.
